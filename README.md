# AI Resume Analyzer

AI Resume Analyzer - Hackathon Practice Project.

## Project Goal

Build a modular resume analysis application where a user can upload a resume,
select a target job role, and receive structured AI-powered analysis.

## Technology Stack

### Frontend
- React
- JavaScript
- CSS

### Backend
- Python 3.10.11
- FastAPI
- Uvicorn

### Resume Parsing
- PyMuPDF
- python-docx

### AI
- Approved LLM API / AI service

### Database
- PostgreSQL

### Testing
- Pytest
- API testing
- Browser testing

### Version Control
- Git
- GitHub

## Modules

1. Resume Upload & Parsing
2. AI Resume Analysis
3. Job Matching
4. Results Dashboard
5. Integration & Testing
